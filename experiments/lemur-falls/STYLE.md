# Road to OMACON — visual rules

Reference: https://www.reddit.com/r/omarchy/ and the supplied community-registry,
installer and OMACON images. This is our interpretation, not an official brand guide.

- Use the installed Omarchy palette through `style.py`.
- One dark panel surface, square corners, one-pixel cream border, 12px text inset.
- Monospace throughout: 11px headings, 12px body, 10px concise control hints.
- Secondary text mixes foreground into background for better contrast.
- Green: safe / ready. Cyan: connections. Orange: work / growth. Red: danger.
- Keep the source screensaver, recognizable logos and original OMACON artwork.
- Animation communicates state: docking pulses, charge compression, growth,
  impacts and arrival confetti. No decorative architecture or repeated texture.
- Physics coordinates never change to accommodate cosmetic padding.

## Nostalgic obstacle windows

Windows uses an original code-drawn Bliss-inspired sky, drifting clouds and green
hills. Apple uses the six-color retro silhouette peeking over destructible bricks,
inside blue outer chrome and an inset traffic-light window with mismatched corner
radii. Only the Apple client gets a temporary rounded-corner compositor rule;
it is removed on exit. Both retain their existing end-of-platform collision boxes.
